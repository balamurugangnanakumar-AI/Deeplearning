## Projects

### CIFAR Vision AI

A Flask application for classifying images into the ten CIFAR-10 classes. Includes a trained model, downloadable CIFAR-10 sample images, training and evaluation scripts, and tests.

- [Application setup, training, and API documentation](CIFAR10/README.md)
- Run locally from the project directory with `python run.py` and open `http://127.0.0.1:5000`.
